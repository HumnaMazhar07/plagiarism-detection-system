# 📄 Assignment Duplication Checker (Plagiarism Detection System)

This project is a Java-based application that checks assignment duplication by comparing text files and calculating similarity between submissions. It is designed to help detect plagiarism in academic work.

---

## 🚀 Features

- 📁 File upload and reading support  
- 🔍 Text comparison between multiple assignments  
- 📊 Similarity detection based on word matching logic  
- ⚠️ Duplicate detection system  
- 🧠 Simple algorithm-based plagiarism analysis  
- 💻 Console-based / desktop Java application  

---

## 🛠️ Technologies Used

- Java  
- File Handling (I/O Streams)  
- String Processing  
- Basic Algorithms (Similarity Logic)  
- OOP Concepts  

---

## ⚙️ How It Works

- User uploads or selects assignment files  
- System reads file content  
- Compares text using word-by-word matching logic  
- Calculates similarity percentage  
- Displays duplication result (safe / partially similar / duplicate)

---

## 📌 Key Concepts Applied

- Object-Oriented Programming (OOP)  
- File Handling in Java  
- String manipulation  
- Basic algorithm design for text comparison  

---

## 📊 Example Output

- Assignment A vs Assignment B → 85% Similarity  
- Result → ⚠️ High chance of duplication detected  

---

## ▶️ How to Run

1. Clone the repository  
2. Open project in IntelliJ / NetBeans / Eclipse  
3. Run main Java file  
4. Provide file paths of assignments  
5. View similarity results
